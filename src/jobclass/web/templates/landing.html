Occupation Intelligence

Federal agencies publish rich labor market data — occupation taxonomies, employment counts, wage distributions, skill profiles, and employment projections — but spread across different bureaus, file formats, and release schedules. This project curates those sources into a single dimensional warehouse where every table joins on the SOC occupation code, making it possible to ask questions that span wages, skills, and outlook in one query.

Four BLS programs feed the pipeline: the Standard Occupational Classification (taxonomy), the Occupational Employment and Wage Statistics (employment and wages by geography), O*NET (skills, knowledge, abilities, and tasks), and Employment Projections (10-year outlook). The warehouse tracks multiple data vintages, adjusts wages for inflation, computes year-over-year trends, and publishes everything as both a live API and a static site.
